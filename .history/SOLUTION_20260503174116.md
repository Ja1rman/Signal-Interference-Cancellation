# SMILES-2026 Signal Interference Cancellation Solution

## Reproducibility

Tested with Python 3.12. The repository is runnable from a clean checkout with:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python applicant_solution.py
```

`applicant_solution.py` downloads `challenge.mat` from the Google Drive file id in
the starter code when the file is not already present. If the network blocks the
download, place `challenge.mat` next to `applicant_solution.py` and rerun the
same command. On networks with a local TLS proxy, the download step can be run
with:

```bash
SMILES_ALLOW_INSECURE_DOWNLOAD=1 python applicant_solution.py
```

The final recorded result is written to `results.json`:


## Final Approach

The final solution keeps the provided TX nonlinear model and adds an explicit
spatial external-interference stage:

1. Fit the provided TX-driven nonlinear prediction with
   `helpers["fit_tx_prediction"]`.
2. Subtract that TX estimate and filter the residual in the scoring band.
3. Estimate the dominant spatially coherent component by taking the leading
   eigenvector of the 4-channel residual covariance, producing a rank-1
   projection.
4. Fit a single complex scale for that rank-1 component after the scorer's band
   filter, so the subtraction is calibrated in the same domain as the metric.
5. Refit the TX model once after the first external estimate, then recompute and
   subtract the final rank-1 external estimate.

This matches the task validity model: the removed signal is explainable as a
TX-driven nonlinear component plus a shared rank-1 component across RX channels.
The rank-1 external stage contributes most of the improvement over the baseline.

I also made the entrypoint more reproducible: imports no longer trigger a full
dataset download, the script has a `main()` guard, and dependencies are listed in
`requirements.txt`.

## Experiments and Discarded Ideas

The first baseline-only version simply called the provided `baseline(...)` and
scored about 4 dB. It did not address the external coherent source described in
the task, so it left a large common residual in the scoring band.

A direct unscaled rank-1 subtraction improved the residual structure but was less
controlled because the scorer applies the band filter to the removed component.
The final version fits the rank-1 scale after that same filter, which reduced
under/oversubtraction.

I avoided adding broader nonlinear TX terms outside the provided helper model.
Those terms could overfit the capture, increase runtime and memory pressure, and
risk failing the explainability check if the removed component was not aligned
with the scorer's TX model.
